## Run locally

This is a static website. You can run it locally without a build step:

1. Clone the repository.
   ```bash
   git clone https://github.com/SRIKALYANBHAVANTHI/srikalyanbhavanthi-portfolio.git
   ```
2. Open the project folder.
   ```bash
   cd srikalyanbhavanthi-portfolio
   ```
3. Open `index.html` in your browser, or use the VS Code Live Server extension.
